# Fastlane — App Store release notes

Cronica uses [Fastlane](https://fastlane.tools) to push localized **What's New** text to App Store Connect in one command.

## One-time setup

1. Use Ruby 3.2+ (see `.ruby-version`) and install gems:

   ```bash
   bundle install
   ```

2. Create an **App Store Connect API key** (Users and Access → Integrations → App Store Connect API). Store the `.p8` file outside the repo.

3. Export credentials:

   ```bash
   export APP_STORE_CONNECT_KEY_ID="YOUR_KEY_ID"
   export APP_STORE_CONNECT_ISSUER_ID="YOUR_ISSUER_UUID"
   export APP_STORE_CONNECT_KEY_PATH="$HOME/.appstoreconnect/AuthKey_YOUR_KEY_ID.p8"
   ```

## Every release

Edit the translated source files under `fastlane/release_notes/` (one file per App Store locale), then upload:

```bash
bundle exec fastlane ios upload_release_notes
```

### Store locales

| File | App Store Connect language |
|------|---------------------------|
| `en-US.txt` | English (U.S.) — primary |
| `en-AU.txt` | English (Australia) |
| `en-CA.txt` | English (Canada) |
| `en-GB.txt` | English (U.K.) |
| `fr-FR.txt` | French |
| `fr-CA.txt` | French (Canada) |
| `de-DE.txt` | German |
| `it.txt` | Italian |
| `pt-BR.txt` | Portuguese (Brazil) |
| `pt-PT.txt` | Portuguese (Portugal) |
| `sk.txt` | Slovak |
| `es-MX.txt` | Spanish (Mexico) |

When the English copy changes, update `en-US.txt` first, then refresh the other locale files before uploading.

## Other lanes

| Lane | Purpose |
|------|---------|
| `bundle exec fastlane ios sync_release_notes` | Copy `release_notes/*.txt` → `metadata/` |
| `bundle exec fastlane ios upload_metadata` | Upload whatever is in `fastlane/metadata/` |
| `bundle exec fastlane ios download_metadata` | Pull current ASC metadata (bootstrap) |

## Notes

- Upload the IPA/build via Xcode Organizer or Transporter; this tooling is **metadata only**.
- `fastlane/metadata/` is generated by `sync_release_notes` — edit sources in `fastlane/release_notes/` instead.
